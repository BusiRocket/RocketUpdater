**§3a — `sparkledrift.sh` body** (report-only; the naive `grep 'sparkle:shortVersionString="'` misses OBS/iTerm2 entirely):

```sh
for a in /Applications/*.app /Applications/*/*.app "$HOME"/Applications/*.app; do
    [ -d "$a" ] || continue
    u=$(/usr/libexec/PlistBuddy -c 'Print :SUFeedURL' "$a/Contents/Info.plist" 2>/dev/null) || continue
    case "$u" in https://*) ;; *) echo "$(basename "$a") feed=unsupported"; continue ;; esac
    v=$(/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' "$a/Contents/Info.plist" 2>/dev/null) || v="?"
    xml=$(curl -fsL --connect-timeout 5 --max-time 20 --proto '=https' "$u" 2>/dev/null) \
        || { echo "$(basename "$a") local=$v feed=unreachable"; continue; }
    latest=$(printf '%s' "$xml" | sed -n 's/.*sparkle:shortVersionString="\([^"]*\)".*/\1/p; s/.*<sparkle:shortVersionString>\([^<]*\)<.*/\1/p' | head -1)
    [ -n "$latest" ] || latest=$(printf '%s' "$xml" | sed -n 's/.*sparkle:version="\([^"]*\)".*/\1/p' | head -1)
    [ "$v" = "${latest:-unparsed}" ] && echo "$(basename "$a") ok $v" || echo "$(basename "$a") DRIFT? local=$v feed=${latest:-unparsed}"
done
```

## 6. Scheduling & hardening

**Blocker first:** `RocketUpdater.sh:47` returns early when `[ ! -t 0 ]`, so under launchd `SUDO_AVAILABLE` stays false — `pear`/`pecl` run unprivileged and `osx.sh` skips the purge. And `osx.sh` runs `softwareupdate -ia`, which **freezes under launchd** (it tries to post Notification Center notifications and a daemon cannot launch GUI — [Apple DevForums 701096](https://developer.apple.com/forums/thread/701096)) and can force a restart. **Before scheduling: change `osx.sh` to `softwareupdate -l` + `softwareupdate -d -r` (download-only) and report "restart pending" as a terminal state** — `-R/--restart` does not work on Apple Silicon, and OS installs need an authorized volume owner ([Apple: bootstrap tokens](https://support.apple.com/guide/deployment/use-secure-and-bootstrap-tokens-dep24dbdcf9e/web)).

`LimitLoadToSessionType=Aqua` is deliberate — it guarantees a GUI session, which is what keeps `softwareupdate` from wedging and lets `msupdate`'s privileged helper work. Install:

```sh
mkdir -p ~/Library/Logs/RocketUpdater
plutil -lint ~/Library/LaunchAgents/com.busirocket.rocketupdater.plist
launchctl bootout gui/$UID/com.busirocket.rocketupdater 2>/dev/null

launchctl print gui/$UID/com.busirocket.rocketupdater | grep -i 'last exit'
```

`load`/`unload` are deprecated; **editing the plist requires `bootout` then `bootstrap`** — `kickstart` alone re-runs the stale definition ([launchd.plist(5)](https://keith.github.io/xcode-man-pages/launchd.plist.5.html)). `StartCalendarInterval` fires do **not** happen while the lid is closed on macOS 26 ([Apple DevForums 815034](https://developer.apple.com/forums/thread/815034)) — keep every step idempotent.

**sudoers drop-in** — replaces the `sudo -v` keepalive for the unattended path (a launchd job has no tty to create a timestamp on, and `timestamp_type` defaults to `tty`). Create with `visudo -f`, never an editor:

```sh
sudo install -m 0440 -o root -g wheel /dev/null /etc/sudoers.d/rocketupdater
sudo visudo -f /etc/sudoers.d/rocketupdater
```

```
# Managed by RocketUpdater. Edit only with: sudo visudo -f /etc/sudoers.d/rocketupdater
Cmnd_Alias ROCKET_SWUPDATE = /usr/sbin/softwareupdate --list, \
                             /usr/sbin/softwareupdate --list --include-config-data, \
                             /usr/sbin/softwareupdate -d -r, \
                             /usr/sbin/softwareupdate --background

Cmnd_Alias ROCKET_MAINT   = /usr/sbin/purge, \
                            /usr/sbin/periodic daily weekly monthly, \
                            /usr/bin/dscacheutil -flushcache

cristiandeluxe ALL=(root) NOPASSWD: ROCKET_SWUPDATE, ROCKET_MAINT
Defaults!ROCKET_SWUPDATE !requiretty
Defaults!ROCKET_MAINT    !requiretty
```

Verify without running anything privileged:

```sh
sudo visudo -c -f /etc/sudoers.d/rocketupdater
sudo grep -n includedir /etc/sudoers        # expect: @includedir /etc/sudoers.d
sudo -l -U cristiandeluxe
sudo -n /usr/sbin/softwareupdate --list     # "a password is required" ⇒ argv mismatch
```

Rules that bite: a `Cmnd` written **without arguments permits any arguments**; never NOPASSWD an interpreter, `find`, `tar`, `rsync`, or `installer -pkg <glob>`; the filename must contain no dot; mode must be 0440 root:wheel. **Never put `brew` in sudoers** — Homebrew refuses root and sudo-ing it corrupts `/opt/homebrew` ownership. `pear`/`pecl` are deliberately omitted: they already have a working unprivileged fallback in `pear.sh`.

**Full Disk Access**: `~/Library/Containers/*/Data`, `~/Library/Group Containers`, `~/.Trash` and `~/Library/Safari|Mail|Messages` are TCC-protected. Denials surface as `EPERM`, not `ENOENT`, and `find` prints them per-entry while **still exiting 0**. FDA is bound to a code signature — granting it to `/bin/bash` grants it to every shell and a Homebrew upgrade of that binary silently revokes it. Prefer a signed AppleScript-applet wrapper. Add an FDA probe to the run header: `ls ~/Library/Application\ Support/com.apple.TCC >/dev/null 2>&1 && echo FDA=yes || echo FDA=no`.

**Log rotation** (launchd never rotates) — `/etc/newsyslog.d/rocketupdater.conf`, tab-separated, root:wheel 0644:

```
/Users/cristiandeluxe/Library/Logs/RocketUpdater/*.log	cristiandeluxe:staff	644	7	2048	*	GN
```

**Single-instance guard** — `ThrottleInterval` bounds respawn but not overlap with a manual run. `atrium-lock` is already the house pattern; a `flock`-based equivalent:

```sh
exec 9>"$HOME/Library/Caches/RocketUpdater/.lock"; /opt/homebrew/bin/flock -n 9 || exit 20
```
